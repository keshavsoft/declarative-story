The Grammar of Declarative UI: declarative-tags

Before defining components or blueprints, we define which HTML tags, child rules, text permissions, and attributes are legally allowed.

Why Tags Come First

If someone puts children inside an <input> or text directly inside a <colgroup>, the DOM becomes malformed silently. declarative-tags prevents this by serving as the root HTML grammar dictionary.

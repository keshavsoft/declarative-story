Chapter 1 Deep Dive

Anatomy of a Tag Rule

Why does a table cell allow text and children while <col> and <input> cannot hold child tags? tags.json records these rules explicitly so specs never emit invalid HTML.

Container Tag (<colgroup>)

{
  "allowsTextContent": false,
  "allowsChildren": true,
  "allowedAttributes": ["span"],
  "childTags": ["col"]
}

Void Tag (<input>)

{
  "allowsTextContent": false,
  "allowsChildren": false,
  "allowedAttributes": ["type", "placeholder", "name", "list"]
}

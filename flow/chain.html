Each Layer Owns One Truth

Instead of writing imperative HTML generation code, we separate declarative knowledge into four focused JSON repositories where every layer points downward cleanly.

Tier 1 • Grammar

declarative-tags

Defines legal HTML tag names, void restrictions, and allowed attributes.
Tier 2 • Parts & Shells

declarative-spec

Place where parts are defined: empty container shells and tokenized HTML pieces.
Tier 3 • How to Build

declarative-instructions

Place where we define how to pick a spec part, merge data, and mutate a base shell.
Tier 4 • Collections

declarative-definitions

Place where we document a named recipe: one base shell + a list of instructions.

Why Fail-Safe Rules Follow This Arrow

A rulebook only works because keys flow in one direction: Definitions points to keys in Instructions and Spec; Instructions points to templates in Spec; Spec must obey tags in Tags.

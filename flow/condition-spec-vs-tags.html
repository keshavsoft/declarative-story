Fail-Safe Condition Set 1

Every Spec Blueprint Must Obey Tags

Since Spec is where HTML parts live, checking every node in spec.json against tags.json stops malformed DOM before an instruction ever runs.

Conditions to Check at Spec Level

  • Legal Tag Name: Every object node's tagName (like th, table, col, input) exists as a key in tags.json.
  • Void Element Guard: When tags[tagName].allowsChildren === false (such as col or input), children must not be present or non-empty.
  • Text Content Guard: When tags[tagName].allowsTextContent === false (such as colgroup or table), textContent must be omitted.
  • Allowed Attributes: Every attribute key (or custom data-* / aria-* convention) belongs to the tag's legal attribute rules.

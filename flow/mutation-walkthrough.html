Story 2 of 5

From Recipe to Rendered Table

Consider rendering table.simpleSortable. The definition itself does not look like HTML — it tells the runner which base spec to clone and which instructions mutate it.

Step A • Definition Lookup (definitions.json)
{
  "baseFromSpec": "tableSimple",
  "instructions": ["buildColgroup", "buildHeaderClickable", "buildBody"]
}
Step B • Clone Base Shell (spec.json → tableSimple)

Clones an empty <table> skeleton containing three empty slot markers: data-role="table-colgroup", data-role="table-header-row", and data-role="table-body".

Step C • Mutate Slot-by-Slot (instructions.json)
  • buildColgroup → appends <col> items into table-colgroup
  • buildHeaderClickable → stamps tableHeaderClickable (with ⇅ icon) into table-header-row
  • buildBody → runs 2D row × column cells into table-body
Step D • Hand Completed DOM JSON to json-to-dom

Only after Step C finishes do we have pure HTML-shaped JSON ready for json-to-dom to mount in the browser.

Fail-Safe Condition Set 2

Every Instruction Must Point to a Valid Spec Part

Because Instructions tell the engine how to build onto a spec, every instruction needs both a valid execution shape and real template keys in spec.json.

Conditions to Check at Instructions Level

  • Supported Type: Object instructions define type as one of "single", "rowOnColumn", or "columnOnRow"; option bundles (like set-search) are non-empty step arrays.
  • Template Exists in Spec: For "single" and array steps, templateKey exists in spec.json (e.g., buildHeaderClickable requires spec.tableHeaderClickable).
  • 2D Pair Exists in Spec: For "rowOnColumn" / "columnOnRow", both templateKey.rowKey and templateKey.columnKey exist in spec.json.
  • Valid Destination Target: Every step has destinationPath.fileName === "base" and a parseable jsonPath string when targeting a nested slot.

Three Instruction Shapes

Every key in instructions.json uses one of three shapes so runners know whether to transform once, iterate a 2D matrix, or apply feature option steps.

1. single

Linear / Single

Maps 1D arrays like $.columns via fromCollection or objects via applyTemplate.

2. rowOnColumn / columnOnRow

2D Matrix

Takes both rowKey and columnKey from declarative-spec to stamp table grids or select options.

3. Bundle Array

set-* / *-show-*

Ordered write-step arrays (set-search, set-serial, options-show-button) resolved at runtime from caller options.

Wiring Data & Spec Parts Into a Slot

declarative-instructions is the bridge: it reads runtime input via sourcePath, stamps a template from declarative-spec (templateKey), and writes the result into a destinationPath slot inside the base shell.

buildHeaderClickable (instructions v3)

{
  "type": "single",
  "narration": "Build table header",
  "destinationPath": {
    "fileName": "base",
    "filePath": ["children"],
    "jsonPath": "$..*[?@.attributes['data-role'] == 'table-header-row']"
  },
  "sourcePath": { "fileName": "data", "jsonPath": "$.columns" },
  "templateKey": "tableHeaderClickable",
  "func": "fromCollection"
}

Look how clean that separation is: swapping headers from plain to sortable required only changing templateKey to "tableHeaderClickable" inside a new instruction key!

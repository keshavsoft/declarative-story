Base Shells Wait for Slots to Be Filled

A base shell like tableSimple defines the outer wrapper, classes, and named data-role anchor points where instructions will later inject rows and columns.

Real Slot Structure in tableSimple (spec v4)

{
  "tagName": "div",
  "attributes": { "data-role": "table-parent", "id": "table-parent-id" },
  "children": [
    {
      "tagName": "table",
      "attributes": { "class": "table table-hover table-striped align-middle border mb-0" },
      "children": [
        { "tagName": "colgroup", "attributes": { "data-role": "table-colgroup" }, "children": [] },
        { "tagName": "thead", "children": [{ "tagName": "tr", "attributes": { "data-role": "table-header-row" }, "children": [] }] },
        { "tagName": "tbody", "attributes": { "data-role": "table-body" }, "children": [] }
      ]
    }
  ]
}

Notice that children arrays inside each data-role start empty — declarative-spec defines the frame, never the loop.

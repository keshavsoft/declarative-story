Leaf Parts Hold Design & ${Tokens}

When you want a plain header cell vs a clickable sortable header cell, both are defined cleanly as JSON fragments in spec.json using ${columnName} placeholders.

buildHeader

{
  "tagName": "th",
  "textContent": "${columnName}",
  "attributes": {
    "class": "py-3 px-3 fw-semibold text-uppercase small"
  }
}

tableHeaderClickable

{
  "tagName": "th",
  "attributes": {
    "role": "button",
    "tabindex": "0",
    "data-column": "${columnName}",
    "data-sort-order": "none",
    "data-role": "sortable-header"
  },
  "children": [ ... "${columnName}", "⇅" ]
}

Notice a crucial rule: adding tableHeaderClickable in spec.json defines what it looks like, but nothing runs it until an entry in declarative-instructions points to it!
